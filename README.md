# TD Learning Lab

Code-first demonstrations of tabular TD learning, Monte Carlo comparison, and an optional DQN bridge example.

## Public package status

This is a curated, standalone public package prepared locally. It contains an explicit allow-list of source and example material only. It does not create a remote repository, publish a service, or grant deployment credentials.

## Run locally

Install `requirements.txt`. Run `python examples/random_walk_td_vs_mc.py` for the standard-library example, or `python examples/td0_random_walk.py` to generate figures.

## Boundaries

Teaching demonstrations only. The optional DQN script trains a local CartPole model and does not include a pretrained model.

Read [PUBLIC_SCOPE.md](PUBLIC_SCOPE.md) before adding data, assets, credentials, deployment files, or new claims.
